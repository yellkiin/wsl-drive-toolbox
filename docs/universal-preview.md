# 通用代理预览版说明

本说明对应 `feature/universal-proxy` 的 0.2.0a1 源码。它与 [v0.1.0 稳定版](https://github.com/yellkiin/wsl-drive-toolbox/releases/tag/v0.1.0) 分开交付；计划使用 `v0.2.0-preview.1` 预览标签。新增功能是否已在某台机器上通过验证，应以该次发布的验证记录为准。

## 从原版试用

把预览包解压到单独的内置磁盘目录，启动 `WSL-Drive-Toolbox-Universal.exe`。源码入口仍是 `python start.py`，需要 Windows Python 3.10+ 和目标 WSL Python 3.8+。

选择发行版、Linux 用户并连接后，该用户的 Bash/Zsh 代理配置会改用固定的 WSL localhost HTTP 入口。首次采用此入口需要重新打开终端或应用。预览版与原版会操作所选 Linux 用户的代理配置，分开的 EXE 并不等于配置互相隔离；请依次使用，不要同时让两个版本改同一用户配置。

## 发现与连接

发现依据真实 TCP 监听和协议验证，不把程序名称当作白名单。默认优先系统代理及已知核心，无可用项时扩大本机监听检测；完整检测不扫描局域网或远程主机。检测有时间限制，未确认或未完成的端点不等于不是代理。

支持无认证 HTTP CONNECT、HTTPS 代理和 SOCKS5；混合端口优先 HTTP。HTTPS 代理是客户端与代理服务器之间使用 TLS，与 HTTP 代理转发 HTTPS 网站是不同概念。认证代理、自动代理脚本 PAC 和仅 TUN 模式不属于本预览的代理接入范围。

检测先验证协议及真实转发，连接时再验证选定上游的 HTTPS/TLS。上游可用、WSL 入口已运行和应用实际联网是三项独立结果。NAT 下 Windows 回环专用监听可能仍不可达，工具不会自动放开监听或修改防火墙。

## 固定入口的生命周期

每个 Linux 用户首次建立入口时选择一个可用的 localhost 端口，此后保存该 URL。转发进程仅监听 WSL `127.0.0.1`，将普通 HTTP 和 HTTPS CONNECT 交给所选 HTTP/HTTPS/SOCKS5 上游；不解密 TLS 或安装证书。

切换上游更新入口配置，新连接使用新上游，已建立隧道保持原状。关闭 GUI 不会停止入口；WSL 停止后入口停止，新 shell 加载管理配置时按需启动。应用首次采用入口需要重启，后续使用固定入口的进程无需为每次上游切换重写环境。

“关闭显式代理”关闭本工具管理的设置和入口；“回滚上次配置”恢复上次管理配置及上游。首次安装的回滚会撤销新入口。已启动的应用仍可能持有旧环境变量，关闭或回滚后应重开这些应用。外部编辑发生冲突时会提示，不能假定回滚已经成功。

## 应用诊断怎样解释

诊断由用户主动发起，可调用已安装的 curl、Git、pip、npm、Node 执行只读公共网络查询，不安装包或发送付费 AI 请求。日志不应包含凭据、正文或完整请求 URL；分享结果前仍应核对个人路径和主机信息。

| 结果 | 含义 |
| --- | --- |
| 通过本工具联网 | 工具请求成功，且入口观察到相应目标的新连接。 |
| 已联网，路径未确认 | 请求成功，但未观察到足以确认经过入口的连接。 |
| 代理覆盖提示 | `no_proxy`、Git `http.proxy`、pip、npm 等独立设置可能改变路径；保留原配置并报告来源。 |
| 未安装、不支持或失败 | 该工具没有得到成功路径证据，需查看具体原因。 |

网关模式在受管理的 shell 文件中设置 `NODE_USE_ENV_PROXY=1`；支持该开关的 Node 版本可采用环境代理，不支持的版本不会因此获得代理能力。工具不会修改 `NODE_OPTIONS`。Node 版本、网络库及应用自身配置都会影响采用方式，不能把所有 AI 工具都当作 Node 程序。

可选 Codex 同步面向 **WSL CLI**，只管理 `.env` 中的代理项。诊断报告已安装版本和代理覆盖的一致性，不读取认证文件，不验证模型 API 登录、额度或调用成功，也不能代表 Windows Codex 桌面程序已经采用该配置。

## 验证和打包

运行 `python -m unittest discover -s tests -v` 和 `python -m compileall -q toolbox tests start.py` 检查源码。协议、网关和应用路径测试使用本地夹具与模拟系统适配器；不能据此推断所有代理规则、Node 版本或 AI 工具已经实机兼容。

在安装可选构建依赖后运行 `scripts/build-universal.ps1`，输出 `dist-universal/WSL-Drive-Toolbox-Universal/`。包内包含 `wsl_agent.py`、`gateway.py`、`app_checks.py` 的 WSL 执行源文件。原 `dist/` 和 v0.1.0 发布资产保持独立。真实用户目录的首次配置、升级及回滚仍应在保存工作后由用户发起；开发验证优先使用隔离 Linux HOME。
